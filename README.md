# pairwise-rate-limiter

登录和短信接口一上量，限流就开始被绕过：只按 IP 计数，攻击者换代理池继续打；只按用户名计数，换账号就能刷；窗口按固定整点重置，临界点能双倍放量；成功登录后不重置失败计数；锁定状态只存在进程内，多实例各算各的；`X-Forwarded-For` 整条链都信，伪造头就能换 key；空 key 直接放行；并发请求同时读到旧计数；剩余次数返回负数；重置接口没有鉴权。security/rate_limiter.py 是核心，tests/test_rate_limiter.py 15个红。要修的是：IP 与账号双维度；滑动窗口；成功重置；共享存储；只信可信代理；空 key 拒绝；原子计数；剩余值夹紧；重置鉴权；锁定分级。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
